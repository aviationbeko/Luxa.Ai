## 🚀 Canlı Yayınlama (Render Static Site - 0 TL)

1. [Render.com](https://render.com) paneline git.
2. **New +** > **Static Site** seçeneğine tıkla.
3. Bu depoyu (`aviationbeko/Luxa.Ai`) bağla.
4. **Publish directory:** `.` (veya boş bırak)
5. **Create Static Site** butonuna bas!
6. Birkaç saniye içinde siten kesintisiz olarak yayında!

---

## 🛠️ Yerel Çalıştırma

`index.html` dosyasını doğrudan herhangi bir tarayıcıda açarak veya Python basit sunucusu ile anında test edebilirsin:
```bash
python -m http.server 8000
```
Tarayıcında `http://localhost:8000` adresine git.
